CDFiles — complete source package

FILES
- index.html: website layout
- style.css: design, responsive layout, animations
- script.js: carousel, search, alphabetical artifact listing, favorites, star rating, member reflections, all 10 essential question answers, museum-level reflections, and artifact data
- content/RPH WEBSITE INPUTS (2).docx: original source document
- assets/images/source-photos/: all 83 photos embedded in the source Word document, kept under their original image names
- assets/images/PHOTO_MAP.txt: photo-to-artifact map for easy replacement
- assets/images/artifacts/: primary photo for each artifact entry
- assets/images/signage/: matching museum-signage photos for selected flip cards
- assets/images/members/: Catbagan, Dasoc, Falco portrait photos extracted from the source document
- assets/images/documentation/: ten documentation/selfie photos from the GROUPIE section
- assets/images/destinations/: locally bundled destination photos where the Word document includes suitable photos

ARTIFACT CONTENT
All 30 numbered artifact entries use the text under Description / Historical Background, Historical Significance, and Further Research & Topic Connections (or the equivalent headings used for the Natural History entries) from the supplied Word document. Artifact entries are sorted alphabetically in the display. Flip cards are enabled only for entries with a selected signage photo.

DESTINATIONS
Five destinations are included: Fort San Felipe, Intramuros, National Museum of Anthropology, National Museum of Fine Arts, and National Museum of Natural History. Luneta/Rizal Park are not carousel destinations.

MEDIA STILL NEEDED FROM THE SHARED DRIVE
The Word document contains photos, but it does not contain the vlog video, montage video, or an MP3 music file. Those were not downloadable from the shared Drive folder in this environment. To finish those media elements, place the files here:
- assets/videos/about-vlog.mp4
- assets/videos/group-montage.mp4
The optional music button embeds your supplied YouTube track after the visitor clicks it; playback is off by default. The website links to the shared folder: https://drive.google.com/drive/folders/1fm8vEPKLM-s0ixtg4BlhJuRmblDMSuE-
The music toggle is optional and starts OFF. It opens the YouTube player only after the visitor enables it.

HOW TO RUN
1. Extract the ZIP.
2. Keep index.html, style.css, script.js and the assets folder together.
3. Open index.html in Chrome. For the best experience with browser media, use VS Code's Live Server extension.
